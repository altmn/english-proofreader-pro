# Support

For a reproducible bug report or feature suggestion, use the [GitHub issue tracker](https://github.com/altmn/english-proofreader-pro/issues) and include the relevant plugin version, host context if known, and a minimal synthetic example. Do not include real private writing, confidential material, personal information, or credentials.

For security vulnerabilities, do not use a public issue; follow [SECURITY.md](SECURITY.md). For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This repository contains a skill package, not a hosted service or support contract. Responses are maintainer-dependent; no response or resolution time is guaranteed. Behavior can vary by host and model, and local test results are not a universal behavior guarantee.
