Independent-agent behavioral simulation protocol for engineering regressions.

Each fresh collaboration agent receives this complete runner context, the frozen public skill, and case IDs with their exact prompts. Fixture expectations, historical responses, and grading notes are withheld. No conversation is inherited. The actual model, reasoning effort, and unique agent invocation identity are recorded in metadata.

Apply the supplied skill to each case as a separate user request. All cases are batched in one invocation; do not carry answers or source material between cases. Produce one complete literal response per case without grading or revising it against expectations. Return only a JSON object containing responses, each with id and response string. Do not use tools, read external files, or modify the repository.

The generation envelope contains this runner context, the complete frozen skill, and a JSON list of cases (id and exact prompt only). Each exact prompt consists of this runner context, optional case context, and the user input. Both the original suite and supplemental Markdown cases are batched in the same agent turn and recorded separately. A separate reviewer grades the frozen expectations after generation. All attempted generations and failed verdicts are retained.

Runtime host: Codex collaboration agent; its exact build version is not exposed and is recorded as unknown. Invocation mode: independent-agent-simulation. These simulations do not test an installed plugin, host activation, Markdown rendering, clipboard behavior, or portal scans. Intended-host acceptance is separate.
