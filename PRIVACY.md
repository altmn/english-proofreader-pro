# Privacy

Effective date: October 12, 2026.

English Proofreader Pro is a skills-only instruction package. The publisher operates no server, API, account, analytics, or telemetry for it. The publisher does not collect submitted text or other personal data through the package, does not use submitted text for a separate purpose, does not disclose it to publisher recipients, and does not retain it. Because the publisher does not collect or retain this data, it has no publisher-side retention period or account controls to offer.

Users may provide text that contains personal information. When the skill is used in ChatGPT, Codex, or another compatible host, the host processes the text to carry out the user's requested editing task. The host provider and any services or tools the user asks it to use may receive or process that information under their own terms and privacy practices. The publisher does not control or make claims about their data collection, retention, review, or controls; consult the applicable host and tool providers' privacy notices and use the controls they make available. If a user asks the host to verify a current fact, quotation, citation, source, or usage online, the host may use its own web or connected tools, whose providers may also receive relevant query information.

This notice is publicly available at [the repository's privacy notice](https://github.com/altmn/english-proofreader-pro/blob/master/PRIVACY.md). Publishing the source and this notice does not imply OpenAI directory approval or publication.

## Repository contributions and support

GitHub issues, pull requests, and commit history are public. If you choose to post text, screenshots, or personal information there, that information becomes public and is processed by GitHub under [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Maintainers can read information you submit to the repository; this is separate from using the plugin. Use synthetic examples, not private writing. Do not put sensitive information in a public support request. For a security vulnerability, use the private reporting channel in [SECURITY.md](https://github.com/altmn/english-proofreader-pro/blob/master/SECURITY.md).
