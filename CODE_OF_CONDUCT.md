# Code of Conduct

We want participation in English Proofreader Pro to be respectful, constructive, and welcoming. Treat people with consideration, discuss ideas rather than attacking contributors, and accept feedback in good faith. Harassment, discrimination, intimidation, personal attacks, and publication of another person's private information are not acceptable.

Maintainers may remove or edit harmful contributions and may warn, restrict, or exclude participants whose conduct harms the community. Responses will be proportionate to the situation.

For a moderation request to the project maintainer, tag `@altmn` in a relevant public issue or comment without including private evidence or sensitive personal information. For a private report to GitHub, use the **Report content** option in the issue, pull request, or comment menu and select GitHub Support; this sends the report to GitHub, not the project maintainer. GitHub may also offer a separate report-to-repository-admins option when that feature is enabled. No separate private conduct-reporting channel is provided here, and no response time is guaranteed.

This concise project policy is inspired by the community standards in the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
